# finesseapex here 👋

Turning ideas into small, useful software.

I build interfaces in TypeScript with React and Next.js — usually styled with Tailwind, usually bundled with Vite. Most of my attention goes to the parts people feel rather than see: load times, focus states, how a button behaves when the network is being slow. I like design systems that get adopted because they're pleasant to work with, not because someone said we have to.

#### About me

- 🔭 Polishing a shared component library and shaving milliseconds off a Next.js app.
- 🔭 Currently working on accessible UI
- 🌍 Based in Indonesia
- ✨ I prefer boring solutions that work
- 🚀 Interested in web performance
